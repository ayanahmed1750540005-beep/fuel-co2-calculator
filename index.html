Official IPCC references

  • 2006 IPCC Guidelines, Vol. 2 Energy, Ch. 1 Introduction – Table 1.2: default net calorific values (NCV).
  • 2006 IPCC Guidelines, Vol. 2 Energy, Ch. 2 Stationary Combustion – Table 2.2: default CO₂ emission factors (kg/TJ).
  • Revised 1996 IPCC Guidelines, Workbook Module 1 Energy – Table 1-3: selected NCVs (used for the fuels it lists).
  • 2006 IPCC Guidelines, Volume 2 landing page (all chapters).
  • IPCC Emission Factor Database (EFDB) – for country- or technology-specific factors.
Method: CO₂ (kg) = fuel (kg) × NCV (TJ/kg) × EF (kg CO₂/TJ). NCV in TJ/kg = TJ per 10³ tonnes ÷ 10⁶. The EF already assumes complete oxidation. Results cover CO₂ only (no CH₄ or N₂O). Fuels in the 1996 Workbook table use its NCV; all others use the 2006 Table 1.2 default. Biomass CO₂ is an information item under IPCC 2006 and is not counted in totals. Industrial Wastes has no default NCV.
